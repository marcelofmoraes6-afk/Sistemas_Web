HTML


O HTML (Linguagem de Marcação de Hipertexto) é a linguagem padrão usada para criar e estruturar páginas da web. Ele funciona como o "esqueleto" ou a fundação de um site, organizando textos, imagens, vídeos e links para que o navegador consiga exibir o conteúdo corretamente.

CSS


CSS (que significa Cascading Style Sheets ou Folhas de Estilo em Cascata) é a linguagem usada para definir a aparência visual e o design de uma página na internet.
